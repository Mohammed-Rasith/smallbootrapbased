# Grocery Store UI Project (HTML / CSS / BOOSTRAP)

This project is a **mini frontend web application** that includes three independent modules commonly used in modern web pages:

1. 🛒 **Grocery Product Cards**
2. 📄 **Responsive Form Design**
3. 🎡 **Image Carousel (Slider)**
4. 

## 🚀 Project Overview

This project demonstrates practical frontend development skills using **HTML, CSS, and BOOSTRAP**.  
Each module is designed to be simple, clean, and beginner-friendly — suitable for portfolio and learning purposes and small grocery store .

## 📌 Features

| Module | Description |
|--------|-------------|
| 🛒 **Product Cards** | Displays grocery items in a clean grid layout with price, image, and button. |
| 📄 **Form Module** | Functional form with validation (Name, Email, Address, etc.). |
| 🎡 **Carousel Module** | Auto-sliding image carousel with buttons and indicators. |

---

## 🧑‍💻 Technologies Used

- **HTML5**
- **CSS3 (Flexbox/Grid)**
- **BOOSTRAP (Vanilla)**

No external frameworks were used.  
All UI components are responsive and mobile-friendly.
